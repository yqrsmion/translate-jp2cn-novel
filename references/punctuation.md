# 标点映射规范（按语言对）

## 为什么需要它

不同语言的标点体系不同，翻译时常需把源语言的符号**映射**到目标语言的对应符号。
处理不当会丢掉原文的层级信息——读者分不清"人物对话"和"广播 / 引用"。

> 本文件以 **日 → 中** 作为**内置示例映射**（也是 `scripts/fix_quotes.py` 当前默认实现）。
> 翻译其它语言对时，请参照本文件的"判定规则"思路，替换对应的映射表与脚本实现。

## 示例：日 → 中

日文用**多套括号各司其职**，中文只有 `“”、‘’、《》` 三种主符号。翻译时必然要把
日文的多套符号**映射**到中文的少数符号上。本规范来自一次真实全书翻译的实测统计
（23 万字、4595 段落）。

### 映射表（推荐默认：中文规范优先）

| 日文符号 | 功能 | → 中文 | 实测数量 |
| --- | --- | --- | --- |
| `「」` | 对话 / 直接引用 | `“”` | 2548 → 2597 |
| `『』` **嵌套**在「」内 | 引用中的引用 | `‘’` | 162 |
| `『』` **独立**成段（无「」） | 广播 / 告示 / 独立引用 | 保留 `『』` | 95 |
| `『』` 为**书名 / 作品名** | 作品名 | `《》` | 15 |
| `〈〉` | 固有名称（船名 / 店名 / 建筑名） | 保留 `〈〉` | 8 |
| `──` | 插入说明 | `——` | 245 → 242 |
| `＊` | 场景分隔 | 保留 `＊` | 33 |
| `・` | 中黑点（并列 / 外来语） | 保留 `・` | 23 |
| `◎` | 奥付条目 | 保留 `◎` | 2 |

### 如何判断一个 `『』` 属于哪一类

1. **同一段落内存在 `「」`** → 该 `『』` 是**嵌套引用** → 译作 `‘’`
2. **`『』` 内容为书名 / 作品名**（如 `『日本書紀』`） → 译作 `《》`
3. **整段无 `「」`，且整段基本就是一个 `『…』`** → **独立引用** → 保留 `『』`
4. **长叙述段中嵌入的 `『』`** → 按中文惯例处理（通常 `‘’`），
   **不要**把同段并存的对话引号一起改掉

## 自动化

`scripts/fix_quotes.py` 依据 `.translate/manifest.json` 的「原文段落 ↔ 译文行」1:1 对齐，
逐段精确定位并统一，不靠正则猜。支持 `--apply`（默认 dry-run）。

> 注意：当前脚本内置的是日 → 中映射。翻译其它语言对时，需替换脚本内的映射规则
> （或改为从外部映射文件读取），本文件提供判定思路与示例。

## 常见坑

- **不要把 `〈〉` 改成 `《》`**：`〈〉` 用于船名 / 店名 / 建筑名（如 `〈清白丸〉`、
  `〈ハマボウ〉`），`《》` 只用于书名作品名
- **简体中文不要保留 `「」`**：简体规范是 `“”；「」/『』` 属繁体（台港）规范。
  若译本目标是繁体中文，则 `「」`/`『』` 反而是正确选择
- **不要整段盲目替换引号**：长段落里对话与引用并存时，整段替换会误伤
